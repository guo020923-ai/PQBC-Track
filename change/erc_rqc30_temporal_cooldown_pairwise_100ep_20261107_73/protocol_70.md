# Deterministic feedback-consistent pairwise protocol

The only scientific change from round 68 is causal crop feedback: the same
quarter-shrunk selected box becomes the next-frame RQC search state. On commit,
the native prompt update and pending native context are rolled back so the
feedback box and prompt history cannot silently disagree. KEEP preserves the
native RQC state exactly.

The 30,000-row TRAIN cache is rebuilt on trajectories generated by the fixed
round-68 Epoch100 behavior policy using the same feedback transaction from the
first post-initialization frame, including warmup. Test data and test ground
truth are not read. Training remains fixed at 100 epochs and 187,500 optimizer
steps, with Epoch100 as the only checkpoint. Runtime numerical stabilization is
a technical integrity change: cuDNN benchmarking is disabled, deterministic
cuDNN and a fixed CuBLAS workspace are used in cache extraction and testing.
This installed CUDA/PyTorch stack has no deterministic CUDA implementation for
the source model's cumsum, so that one unsupported operation is explicitly
warn-only and all reports label execution best-effort rather than claiming
strict determinism.

After TRAIN-only calibration, exactly one TNL2K NLBBOX FULL700 development
evaluation is allowed. A fallback threshold may be used only to guarantee an
evaluation result and must be labeled not safety-admitted. There is no retry,
second candidate, intermediate-checkpoint selection or TEST-GT tuning.
