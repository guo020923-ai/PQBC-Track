# 相对原框损害约束：独立监督修改与固定对照

固定旧邻域输入细化器、输出层隔离、原Head/Backbone和限幅。只新增监督项：

L = 2 L_GIoU + 5 L_image_normalized_L1 + mean(ReLU(IoU(original,GT).detach - IoU(refined,GT))).

权重1为预先固定工程起点，未用40条确认结果搜索。损害项对未变或改善样本为0，对变差样本追加实际下降量惩罚；没有额外q/Gate，没有GT推理条件。原定位项负责推动改善，新增项强调避免破坏已有正确框。因此不是“只保守不学习”，但也可能促使输出更接近零，必须报告介入量及收益，不能把少改视为成功。
